# Sanad Travel ERP - نظام إدارة شركات السياحة والحسابات المتكامل ✈️

نظام سحابي ومحلي متكامل لإدارة شركات السياحة والسفر، الطيران، رحلات العمرة والحج، حسابات الوكلاء والموردين، مع ربط منظومة الفاتورة الإلكترونية المصرية (ETA).

---

## 🚀 التشغيل المباشر السريع (Windows)

يمكن تشغيل السيستم بالكامل محلياً مع السيرفر وقاعدة البيانات بنقرة واحدة:
1. انقر نقراً مزدوجاً على الملف: **`RUN_TRAVEL_ERP.bat`**
2. سيتم فحص بايثون وتهيئة قاعدة البيانات `travel_erp.db` وفتح السيستم تلقائياً في المتصفح على الرابط:
   👉 **`http://localhost:5000`**

## 🏗️ البنية البرمجية والهندسية (Architecture)

```
Travel ERP/
├── app/
│   ├── database.py          # محرك قاعدة البيانات وجلسات SQLAlchemy (SQLite / PostgreSQL)
│   ├── models.py            # نماذج البيانات (المستخدمين، الحجوزات، العملاء، الموردين، السندات، المصروفات، ETA)
│   ├── auth.py              # تشفير كلمات المرور ومصفوفة الصلاحيات (RBAC)
│   ├── routes_api.py        # واجهات برمجة التطبيقات RESTful API
│   └── seed.py              # سكربت تعبئة البيانات الأولية الواقعية
├── index.html               # واجهة المستخدم التفاعلية المتطورة
├── run_server.py            # خادم الويب (Flask Backend)
├── RUN_TRAVEL_ERP.bat       # ملف التشغيل السريع لويندوز
├── requirements.txt         # متطلبات بايثون
└── travel_erp.db            # قاعدة البيانات المحلية
```

## 🔌 واجهات برمجة التطبيقات الأساسية (API Endpoints)

| المسار | الطريقة | الوصف |
|---|---|---|
| `/api/auth/login` | `POST` | تسجيل دخول الموظفين والتحقق من الصلاحيات |
| `/api/stats` | `GET` | إحصائيات لوحة التحكم ومؤشرات الأداء KPI |
| `/api/bookings` | `GET, POST` | استرجاع وتسجيل الحجوزات واحتساب الأرباح |
| `/api/bookings/<id>/eta` | `POST` | اعتماد وإصدار فاتورة إلكترونية ETA مع UUID |
| `/api/clients` | `GET` | كشوف حسابات العملاء والأقساط المستحقة |
| `/api/suppliers` | `GET` | حسابات شركات الطيران والموردين والوكلاء |
| `/api/transactions` | `GET, POST` | إصدار سندات القبض والصرف والتسويات |
| `/api/expenses` | `GET, POST` | تسجيل واستعراض المصروفات التشغيلية |
| `/api/reports/profit-summary` | `GET` | تقرير أرباح كل قطاع وصافي ربح الشركة النهائي |
| `/api/audit-logs` | `GET` | سجل مراقبة وتتبع نشاط الموظفين المباشر |

# Sanad Travel ERP (Demo) - نظام إدارة شركات السياحة والحسابات

نسخة تجريبية (Interactive Live Demo) لنظام السحابي المتخصص في إدارة شركات السياحة، الطيران، رحلات العمرة والحج، وحسابات الوكلاء والموردين مع دعم منظومة الفاتورة الإلكترونية المصرية (ETA).

---

## 🌟 الميزات الرئيسية للنسخة التجريبية

- **📊 لوحة مؤشرات أداء حية (KPI Cards):**
  - متابعة إجمالي المبيعات والأرباح الصافية تلقائياً.
  - حساب المديونيات الآجلة للعملاء.
  - متابعة أرصدة العملات الأجنبية (الريال السعودي والدولار).

- **➕ تسجيل فوري للحجوزات والملفات:**
  - إضافة حجوزات طيران، برامج عمرة، حجوزات فنادق وتأشيرات.
  - احتساب صافي الربح الفوري لكل حجز بناءً على سعر البيع والتكلفة.
  - دعم العملات المتعددة (EGP, SAR, USD).

- **🧾 تكامل الفاتورة الإلكترونية (ETA):**
  - إمكانية إصدار واعتماد الفاتورة الإلكترونية وتوليد الرقم التعريفي UUID بنقرة واحدة.

---

## 🚀 تشغيل الديمو محلياً

يمكن فتح ملف `index.html` مباشرة في أي متصفح إنترنت (Google Chrome, Edge, Firefox, Safari) بدون الحاجة إلى تثبيت أي برامج أو خوادم.
